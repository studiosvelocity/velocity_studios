How a project survives the semester

The pipeline every build in this portfolio actually went through, deadline permitting.

01

Spec it on paper

Whiteboard the schema and the screens before touching an IDE — usually the night before it's due.

02

Build the ugly version

Get the logic working first. Styling, validation, and dignity come later.

03

Break it on purpose

Feed it bad input until it stops crying, then patch whatever it exposed.

04

Ship & demo

Push to the shared machine, screen-record a backup demo, present like nothing broke last night.
